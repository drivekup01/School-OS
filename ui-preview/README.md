# สำเนาทดลอง UI ตารางสอน

สำเนาฐานสำหรับเปรียบเทียบหน้าตาเดิมกับการปรับ UI ในขั้นต่อไป ไม่เปลี่ยนหน้า index.html ของระบบจริง

- ข้อมูลตั้งต้นคัดลอกจาก JSON ที่เผยแพร่อยู่แล้วใน repository
- บัญชีในสำเนาเป็นผู้ดูแลจำลอง ไม่ใช้บัญชีหรือ token จริง
- บันทึกข้อมูลทดลองไว้ใน sessionStorage โดยใช้ชื่อแยกจากระบบจริง
- ปิด Apps Script ทั้งระบบหลักและระบบลา และบล็อก fetch ที่ออกนอกโฟลเดอร์สำเนาหรือไม่ใช่ GET/HEAD
- ปุ่มล้างสำเนาคืนข้อมูลตั้งต้น โดยไม่ล้างข้อมูลระบบจริง
- การทดลองนี้ยังไม่ตรวจยืนยันการเชื่อมต่อ backend สิทธิ์บัญชีจริง หรือการบันทึกจริง
- บันทึกทั่วไปและการเปลี่ยนโหมดเป็นการจำลอง ส่วนประกาศและระบบลายังไม่เปิดการบันทึกในสำเนา

เปิดผ่าน `/School-OS/ui-preview/` และทดสอบหน้าครู วิชา ห้องเรียน คาบเรียน ตารางรายครู ตารางชน และส่งออกก่อนเปลี่ยนรูปแบบ UI

## UI ใหม่

เพิ่ม budget-theme.css และ budget-theme.js เฉพาะสำเนา: sidebar ม่วง, วันเวลา, ไอคอนเส้น, การ์ดสรุป, เมนูมือถือ, ปุ่มและตารางชุดใหม่ โดยคง IDs และตัวจัดตารางเดิม ใช้สีรายวิชาและสถานะชนเดิม และไม่เปลี่ยน CSS สำหรับงานพิมพ์

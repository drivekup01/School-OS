# School-OS

ระบบบริหารจัดการโรงเรียน

## Description

School-OS เป็นระบบที่ช่วยจัดการข้อมูลภายในโรงเรียน
เช่น ตารางสอน ครู นักเรียน วิชา ห้องเรียน และข้อมูลพื้นฐานต่างๆ

## Features

- จัดการข้อมูลครู
- จัดการข้อมูลนักเรียน
- จัดการรายวิชา
- จัดการห้องเรียน
- สร้างและจัดการตารางสอน

## Technology

Frontend:
- React

Backend:
- Node.js
- Express

Database:
- MySQL

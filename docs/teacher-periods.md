# คาบเฉพาะครู

เมนูคาบเรียนและวันเรียนมีตัวเลือก “เฉพาะครู” ท้ายคาบปกติ คาบนี้ยังแสดงและเลือกรายวิชาได้ในตารางรายครู รวมถึง PLC โดยไม่ใช้โควตาวิชา และไม่แสดงในตารางนักเรียน ตัวอย่างตารางนักเรียน Word/PNG หรือระบบจัดตารางนักเรียนอัตโนมัติ

คาบพักใช้ตัวเลือกนี้ไม่ได้ ถ้ามีวิชานักเรียนอยู่ในคาบแล้ว ต้องย้ายหรือลบวิชานั้นก่อนเปลี่ยนประเภทคาบ การยกเลิกเฉพาะครูทำให้คาบกลับไปแสดงในตารางนักเรียน โดยคาบครูยังอยู่ตามเดิม

ข้อมูลใช้ slots[].teacherOnly และ teacherSched เดิม เก็บค่า teacherOnly ไว้เมื่อแท็บรุ่นเก่าส่งข้อมูลที่ยังไม่รู้จัก field นี้ ตรวจทั้งข้อมูล private/public และป้องกันวิชานักเรียนในคาบเฉพาะครู

หน้าส่งออกตารางห้องเรียนเหลือ Word ตารางเรียน และ PNG ตารางเรียน Word ใช้ TH SarabunPSK และแปลงขนาด CSS ของ PNG จาก px เป็น half-point (1 px = 0.75 pt) ตามองค์ประกอบหัวเรื่อง วิชา ครู ห้อง และลายเซ็น

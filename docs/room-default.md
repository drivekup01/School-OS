# ห้องเรียนหลัก

กำหนด “ห้องเรียนหลัก” ในเมนูห้องเรียน/ชั้นเรียนของแต่ละห้อง เช่น ม.1/1 ใช้ห้อง 123 ระบบใช้ค่านี้เมื่อคาบนั้นไม่มี learnRoom ที่ระบุไว้เป็นพิเศษ

ช่องห้องเรียนในตารางแก้ได้เฉพาะคาบตามเดิม หากล้างข้อความและออกจากช่อง จะกลับมาใช้ห้องหลัก การเปลี่ยนห้องหลักมีผลต่อทุกคาบที่ใช้ค่าเริ่มต้น แต่ไม่เปลี่ยนคาบที่ระบุห้องอื่นไว้แล้ว

เก็บค่าใน `rooms[].baseRoom` และคง override เดิมใน `sched[cell].learnRoom` ไม่คัดลอกค่าห้องหลักลงทุกคาบ จึงปรับห้องหลักภายหลังได้โดยไม่ทำข้อมูลซ้ำ

แสดงห้องที่ใช้งานจริงในตารางนักเรียน ตารางรายครู ตารางรวมรายวัน และส่งออก/พิมพ์ คาบอิสระของครูไม่รับห้องหลักของนักเรียน บันทึกผ่าน revision/private/public version ชุดเดิม และรักษาค่าห้องหลักเมื่อแท็บรุ่นเก่าส่งข้อมูลที่ไม่รู้จัก field นี้

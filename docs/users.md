# Users

## 1. Administrator

หน้าที่:
- จัดการระบบ
- จัดการผู้ใช้งาน
- ตั้งค่าข้อมูลโรงเรียน


## 2. Teacher

หน้าที่:
- ดูตารางสอน
- ลางาน
- ดูงานที่ได้รับ
- กรอกคะแนน
- รับแจ้งเตือน


## 3. Head Department

หน้าที่:
- อนุมัติการลา
- จัดการครูในกลุ่มสาระ
- จัดการครูสอนแทน


## 4. Director

หน้าที่:
- ดูภาพรวมโรงเรียน
- ดูรายงาน

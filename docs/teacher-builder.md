# จัดตารางรายครู

เมนู “สร้างตารางรายครู” เปิดเฉพาะฝ่ายวิชาการและผู้ดูแล ใช้ตารางวัน/คาบและรูปแบบเดียวกับการสร้างตารางนักเรียน เลือกครูแล้วลงวิชาอิสระในแต่ละช่อง ไม่ต้องเลือกห้องนักเรียน ไม่จำกัดตามรายวิชาที่ครูสอนได้ และไม่ใช้โควตาคาบวิชา

คาบที่ผูกห้องเรียนอยู่แล้วแสดงจาก `sched` ชุดเดิม พร้อมปุ่มกลับไปแก้ตารางห้องเรียน ไม่ทำสำเนาคาบเหล่านั้น วิชาอิสระเก็บใน `teacherSched` แยกตามรหัสครู คาบ และวัน และไม่สร้างห้องนักเรียนจำลอง

วิชาอิสระแสดงรวมในตารางรายครู ยอดคาบ ภาระงาน ตารางรวมรายวัน และส่งออก Word/พิมพ์ การตรวจครูว่างและจัดสอนแทนถือว่าครูมีกิจกรรมเป็นไม่ว่าง กิจกรรมที่ไม่มีห้องไม่สร้างงานสอนแทนห้องเรียนโดยอัตโนมัติ

ครูและวิชาอ้างอิงด้วย ID ชื่อที่แสดงตามรายการปัจจุบัน เลือกตัวเลือกว่างเพื่อลบคาบอิสระได้ การเปลี่ยนครู/วิชาในคาบห้องเรียนยังแก้จากตารางนักเรียน

บันทึกผ่าน Firebase timetableApi และ revision เดียวกับตารางเดิม พร้อม private/public version และ audit เมื่อแท็บรุ่นเก่าส่งข้อมูลที่ยังไม่รู้จัก teacherSched ระบบเก็บคาบอิสระไว้เพื่อป้องกันการหายของข้อมูล

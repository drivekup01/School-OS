# School OS Vision

## Vision

สร้างระบบกลางสำหรับโรงเรียน
ที่ช่วยให้ครูและบุคลากรสามารถจัดการงานประจำวัน
จากระบบเดียว ลดการทำงานซ้ำซ้อน และลดเวลางานเอกสาร

## Core Principle

"กรอกข้อมูลครั้งเดียว ใช้งานได้ทุกระบบ"

## Main Goals

1. ลดเวลาการทำงานของครู
2. ลดการกรอกข้อมูลซ้ำ
3. เชื่อมโยงข้อมูลระหว่างระบบ
4. ใช้งานง่ายสำหรับทุกระดับผู้ใช้
